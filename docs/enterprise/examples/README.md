# Synthetic examples

**Everything in this directory is synthetic.** The organizations, systems,
evidence and reviewers are invented, and the evidence digests are computed
over placeholder values. No file here is the result of a real assessment or
contains customer data.

| File | What it is |
| --- | --- |
| `rn-sv-founding-assessment.synthetic.md` | The commercial report as a customer reads it |
| `rn-sv-founding-assessment.synthetic.json` | Its structured content |
| `rn-sv-founding-assessment.synthetic.manifest.json` | The content, Markdown and manifest digests |
| `rn-sv-founding-assessment.synthetic.release.json` | The release record of the synthetic human approval |

The files are generated by
`src/enterprise/__tests__/assurance-rep-01-commercial-report.test.ts` and
checked against its output on every run. See
`docs/enterprise/AOC_ASSURANCE_COMMERCIAL_REPORT.md`.

The independent verifier `scripts/assurance/verify-commercial-package.mjs`
also verifies these four files once they are copied under their delivery names
(`report.md`, `report.json`, `integrity-manifest.json`, `release-record.json`).
What such a verification does and does not show is set out in
`docs/enterprise/ASSURE_PILOT_01_COMMERCIAL_DRY_RUN.md`.

The example is produced by generator `aoc.assurance.commercial-report.v3`
(ASSURE-CLAIMS-01): its report states no release status of its own
(ASSURE-REL-01C), and it keeps internal review, internal release approval,
external review and commercial authorization apart.

`historical/` holds the same example as earlier generators produced it, byte
for byte, kept unedited to prove that historical packages still verify and
re-render identically:

- `rn-sv-founding-assessment.synthetic.v1.*`: generator v1, including its
  "not yet released" wording;
- `rn-sv-founding-assessment.synthetic.v2.*`: generator v2, including its
  statement that the release approver acts as the controlled review (GF-01),
  which v3 corrects. These are the exact files that were committed here as
  the current example before ASSURE-CLAIMS-01.

They are equally synthetic.
